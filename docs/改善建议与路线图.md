## 二、近期完成（2026-06-23）

### 功能

- **自定义练习**：主菜单紫色入口；题量 10/20/30/50；范围（全部/单选/多选/领域）；筛选（不限/从未做过/正确率阈值）
- **解析富文本 UI**（`gui/explanation_formatter.py`）：正确答案 / 错误选项分析 / 重点考点分区；`**关键词**` 蓝色加粗；冒号前关键词自动高亮
- **练习字体调节**：顶栏 A− / A+（85%–135%），偏好持久化到 `user_data.json`
- **解析展开/收起**：答后默认全屏展开解析，可手动缩回

### 体验修复

- 术语标注**仅保留在解析区**（题干、选项不再附加中文）
- 术语表统一（如 `Cost Explorer` / `AWS Cost Explorer` 均为「成本分析器」）
- 选项文字按容器宽度自动换行（`gui/wrapped_label.py`），修复高 DPI 下横向溢出
- 单选题点击选项文字区：修复「你的答案」显示坐标而非 A/B/C/D 的回调参数问题
- 字体调节时解析被清空：用 `_explanation_full_visible` 标志修复

### 题库修复

- 多选题 M91 / M92 / M96 / M97 / M99 / M104：题干「选择三项」→「选择四项」（与 4 个正确答案一致）
- 单选/多选库交叉重复题干：**0** 道；题型混入：**0** 道

### 工程

- 新增模块：`custom_practice.py`、`custom_practice_view.py`、`explanation_formatter.py`、`wrapped_label.py`
- 新增测试：`test_custom_practice`、`test_explanation_formatter`、`test_wrapped_label`；题库一致性测试扩展
- `quiz_view` / `mock_exam` 换行逻辑收敛至 `wrapped_label.py`
