「内置计算能力，可在本地运行 Lambda 或 EC2 实例处理数据」是正确的。

AWS Snowball Edge 相比普通 Snowball，增加了本地计算能力，支持在设备上直接运行 AWS Lambda 函数或 EC2 实例，对数据进行预处理、过滤、转换后再传回 AWS，大幅减少需要传输的数据量。

其他选项分析：

「支持更大的存储容量」是错误的：虽然 Snowball Edge 容量也很大，但核心差异是计算能力。

「更快的网络速度」是错误的：网络速度不是 Snowball Edge 的主要卖点。

「完全免费」是错误的：Snowball Edge 是付费服务。

**重点考点 / 关键词补充：**
- Snowball Edge = 存储 + 计算
- 适合场景：数据预处理、边缘计算、断网环境下的数据收集
- 普通 Snowball 只有存储功能
