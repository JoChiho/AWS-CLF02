# AWS CLF-C02 题库「选项太短导致正确答案容易被猜出」专项审计报告（2026-05 重新全面扫描）

## 执行摘要

- **总题目**：245 道（单选 136 + 多选 109）
- **发现问题**：**102 道**（High 严重度 44 道，Medium 需关注 58 道）
- **问题占比**：约 **41.6%** 的题目存在「干扰项过短、细节不足」导致考生可通过长度/详细程度直接猜中正确答案的缺陷。

**核心问题**：大量题目的错误选项（干扰项）写得过于简短、泛化（常见 7~14 字），而正确答案则写得详细具体。考生无需真正掌握知识，仅凭“选最长/最详细的那个”即可高概率答对，严重降低题目鉴别度。

## 判定标准（本次审计使用）

- **High（必须优先修复）**：
  - 正确答案长度 ≥ 平均干扰项 2.0×，或
  - 存在 3 个以上 <15 字极短干扰项且正确答案 >25 字，或
  - 存在 <10 字超短干扰项
- **Medium（建议改善）**：
  - 1.6× ≤ ratio < 2.0，或存在 2 个短干扰项，或选项长度标准差过大

## 根本原因分析

1. 早期题目编写时追求“简洁错误选项”，但过度简化导致失去迷惑性。
2. 部分概念题（计费、扩展、缓存、存储类等）干扰项直接用极简反义词或错误关键词堆砌。
3. 多选题中偶尔出现“一个长正确 + 几个短错误”的情况。
4. 缺乏统一的“选项长度与细节均衡”审查标准。

## 修复建议与优先级

### 立即行动（44 个 High）
- 所有 High 题目必须重写至少 2~3 个干扰项。
- **目标**：单选题 4 个选项长度控制在 ±8 字以内；错误选项应采用“具体但错误”的场景/限制/混淆点，而非泛化短语。
- 示例修复方向（以 S24 为例）：
  - 原 D “完全免费” → “仅在免费套餐期内免费，超出后按实际请求计费”
  - 原 A “按小时预留容量” → “仅支持预置容量模式，不支持按需模式”

### 中期改善（58 个 Medium）
- 逐步把 ratio 1.6~2.0 的题目也拉平。

### 长期质量门禁
- 新增题目时强制执行“选项长度方差 < 12”检查。
- 所有题目每季度运行本审计脚本，回归验证。
