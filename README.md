# AWS CLF-C02 认证考试刷题系统

> **高效备考 AWS Certified Cloud Practitioner (CLF-C02) 的中文练习工具**  
> 210 道高质量题目 + 领域分类练习 + 完整持久化进度追踪

---

## ✨ 功能亮点

- **210 道精选题目**（121 单选 + 89 多选），全部配有详细解析和「重点考点」补充
- **按官方四大领域分类练习**（云概念、安全与合规、技术与服务、账单定价与支持）
  - Cloud Concepts: 45 题
  - Security and Compliance: 47 题
  - Technology and Services: 75 题
  - Billing, Pricing, and Support: 49 题
- **完整持久化系统**（2026-05-28 新增）：
  - 最近 10 次练习历史记录（模式、得分、正确率、用时）
  - 永久错题本（每道题累计正确/错误次数 + 错误率排序）
  - 正确率趋势统计 + 简单进步提示
  - 支持从错题本一键启动针对性练习
- 响应式暗色 GUI（支持窗口自由缩放，字体/按钮自适应）
- 多选题需主动「提交答案」后才显示完整正误解析（更接近真实考试）
- 保留传统 CLI 模式（`--cli`）

---

## 🚀 快速开始

### 图形界面（推荐）

```bash
# 1. 安装依赖
pip install customtkinter

# 2. 启动程序（默认进入 GUI）
python main.py
```

### 命令行模式

```bash
python main.py --cli
```

首次完成任意一套练习后，系统会自动在项目根目录生成 `user_data.json`，用于保存你的历史记录和错题统计。

## 📖 使用说明

### 主菜单结构

1. **传统模式**
   - 单选题题库（46 题）
   - 多选题题库（49 题）
   - 全部题目（95 题）

2. **按考试领域分类练习**（官方四大领域）
   - 云概念
   - 安全与合规
   - 技术与服务
   - 账单、定价与支持

3. **我的学习**（持久化功能）
   - **历史记录（近10次）**：查看最近练习的详细数据
   - **错题本（累计统计）**：按错误率排序，支持「练习全部错题」
   - **我的统计与趋势**：平均正确率、最高/最低、简单进步提示

### 答题流程
- 单选题：点击选项后立即显示解析
- 多选题：勾选后必须点击「提交答案」才显示完整解析（可重复提交更新）
- 随时可「上一题 / 下一题」自由翻阅
- 点击「完成测试」查看得分并自动保存进度

├── user_data.json          # 你的个人进度（运行后自动生成）

## 💾 进度数据说明
